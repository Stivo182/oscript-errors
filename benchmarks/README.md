# Бенчмарки

Каталог содержит бенчмарки основных пользовательских сценариев библиотеки. Измеряемые операции вызываются
через публичный программный интерфейс, поэтому результаты отражают полную стоимость сценария для потребителя.

## Состав

- [Создание и обёртывание ошибок](БенчмаркСозданияИОбертыванияОшибок.os)
- [Создание с форматированием описания](БенчмаркСозданияОшибокСФорматированием.os)
- [Классификация неструктурированных ошибок](БенчмаркКлассификацииОшибок.os)
- [Масштабирование классификации по числу правил](БенчмаркМасштабированияКлассификацииОшибок.os)
- [Разбор и поиск по цепочке](БенчмаркРазбораИПоискаОшибок.os)
- [Материализация разбора](БенчмаркМатериализацииРазбораОшибки.os)
- [Поиск в материализованной выборке](БенчмаркПоискаВВыборкеОшибок.os)
- [Проверка аргументов](БенчмаркПроверкиАргументов.os)
- [Формирование представлений](БенчмаркПредставленияОшибок.os)
- [Диагностическое представление данных](БенчмаркДиагностическогоПредставленияДанных.os)

Внутренние методы следует измерять временными диагностическими бенчмарками во время конкретной оптимизации.
В постоянный набор они не входят, поскольку изменение внутренней реализации делает такие результаты несопоставимыми.

## Запуск

Для запуска установите `BenchmarkOneScript`:

```shell
opm install benchmark
```

Запуск всех бенчмарков:

```shell
benchos run ./benchmarks
```

Запуск отдельного набора:

```shell
benchos run ./benchmarks/БенчмаркМатериализацииРазбораОшибки.os
```

Короткий диагностический запуск:

```shell
benchos run --iterationCount 2 --warmupCount 1 ./benchmarks
```
