# ФабрикаОшибок

Публичный модуль создания структурированных ошибок. Функции возвращают стандартную
`ИнформацияОбОшибке`, совместимую с `ВызватьИсключение`, но не выбрасывают создаваемую
предметную ошибку. При нарушении контракта собственных аргументов функция может выбросить
структурированное исключение.

## Создать

```bsl
ФабрикаОшибок.Создать(
    <КодОшибки>, <Сообщение>, <Данные> = Неопределено
)
```

Создаёт классифицированную ошибку без причины.

**Параметры:**

| Имя | Тип и значение по умолчанию | Описание |
| --- | --- | --- |
| КодОшибки | `Строка` | Стабильный машинный код ошибки. |
| Сообщение | `Строка` | Человекочитаемое описание ошибки. |
| Данные | `Произвольный = Неопределено` | Связанные с ошибкой данные. |

**Возвращаемое значение:**

`ИнформацияОбОшибке` - новый кадр ошибки.

## ОбернутьКонтекстом

```bsl
ФабрикаОшибок.ОбернутьКонтекстом(
    <Причина>, <Сообщение>, <Данные> = Неопределено
)
```

Добавляет контекст, не изменяя машинную классификацию причины.

**Параметры:**

| Имя | Тип и значение по умолчанию | Описание |
| --- | --- | --- |
| Причина | `ИнформацияОбОшибке` | Непосредственная причина нового кадра. |
| Сообщение | `Строка` | Описание выполнявшейся операции. |
| Данные | `Произвольный = Неопределено` | Связанные с контекстом данные. |

**Возвращаемое значение:**

`ИнформацияОбОшибке` - новый кадр контекста.

## Обернуть

```bsl
ФабрикаОшибок.Обернуть(
    <Причина>, <КодОшибки>, <Сообщение>, <Данные> = Неопределено
)
```

Оборачивает причину новой машинной классификацией.

**Параметры:**

| Имя | Тип и значение по умолчанию | Описание |
| --- | --- | --- |
| Причина | `ИнформацияОбОшибке` | Непосредственная причина нового кадра. |
| КодОшибки | `Строка` | Новый стабильный машинный код ошибки. |
| Сообщение | `Строка` | Человекочитаемое описание ошибки. |
| Данные | `Произвольный = Неопределено` | Связанные с ошибкой данные. |

**Возвращаемое значение:**

`ИнформацияОбОшибке` - новый классифицированный кадр.

## Ошибки

`КодОшибки` должен состоять минимум из двух разделённых точками сегментов. Каждый сегмент начинается с русской или
латинской буквы и далее содержит только буквы, цифры и `_`. Регистр не ограничен. `Сообщение` должно быть непустой
строкой.
`Причина` должна иметь тип `ИнформацияОбОшибке`.

| Код | Условие |
| --- | --- |
| `argument.invalid_type` | Код, сообщение или причина имеют недопустимый тип |
| `argument.required` | Обязательное сообщение не заполнено |
| `argument.invalid_value` | Машинный код имеет неверный формат |

`Данные` могут иметь любой тип и сохраняются как переданы.

## Пример

```bsl
Причина = ФабрикаОшибок.Создать(
    "storage.read_failed",
    "Не удалось прочитать файл",
    Новый Структура("ИмяФайла", "settings.json")
);

Ошибка = ФабрикаОшибок.ОбернутьКонтекстом(
    Причина,
    "Не удалось загрузить настройки"
);

ВызватьИсключение Ошибка;
```

`ОбернутьКонтекстом()` оставляет эффективным код причины `storage.read_failed`. `Обернуть()` добавил бы новый
классифицированный кадр, код которого стал бы эффективным.
