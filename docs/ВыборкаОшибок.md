# ВыборкаОшибок

Выборка классифицированных ошибок с неизменяемым составом. Получается через
[`РазборОшибки.Ошибки`](РазборОшибки.md#ошибки), методы отбора другой выборки или создаётся напрямую.

Неизменяемость относится только к составу и порядку снимков. Пользовательские данные
снимков не копируются и сохраняются по ссылке: изменение исходного мутабельного объекта
будет видно через выборку.

## Создание

```bsl
Новый ВыборкаОшибок(<Снимки>)
```

**Параметры:**

| Имя | Тип | Описание |
| --- | --- | --- |
| **Снимки** | `Массив` из `СнимокКадраОшибки` | Кадры ошибок в физическом порядке |

Выборка принимает только снимки вида `Ошибка`.

Состав исходного массива копируется. Последующие изменения переданного массива не изменяют выборку.

#### Возвращаемое значение

Новая [`ВыборкаОшибок`](ВыборкаОшибок.md) с независимым составом снимков.

#### Ошибки конструктора

| Код | Условие |
| --- | --- |
| `argument.invalid_type` | `Снимки` не являются массивом |
| `argument.invalid_value` | Элемент массива не является снимком классифицированной ошибки |

## Методы

### Снимки

```bsl
.Снимки()
```

Возвращает независимую копию всех снимков в физическом порядке.

#### Возвращаемое значение

Новый `Массив` из [`СнимокКадраОшибки`](СнимокКадраОшибки.md). Изменение состава массива не меняет выборку.

### Первая

```bsl
.Первая()
```

Возвращает первый снимок или `Неопределено` для пустой выборки.

#### Возвращаемое значение

[`СнимокКадраОшибки`](СнимокКадраОшибки.md) или `Неопределено` для пустой выборки.

### Последняя

```bsl
.Последняя()
```

Возвращает последний снимок или `Неопределено` для пустой выборки.

#### Возвращаемое значение

[`СнимокКадраОшибки`](СнимокКадраОшибки.md) или `Неопределено` для пустой выборки.

### Количество

```bsl
.Количество()
```

Возвращает количество снимков.

#### Возвращаемое значение

`Число`: количество ошибок в выборке.

### ЕстьОшибки

```bsl
.ЕстьОшибки()
```

Возвращает `Истина`, если выборка не пуста.

#### Возвращаемое значение

`Булево`: `Истина`, если выборка содержит хотя бы одну ошибку.

### Коды

```bsl
.Коды()
```

Возвращает коды ошибок с сохранением порядка и повторов.

#### Возвращаемое значение

Новый `Массив` из `Строка`.

### Данные

```bsl
.Данные()
```

Возвращает данные ошибок с сохранением позиционного соответствия. Сам массив результата
создаётся заново, но его элементы являются исходными значениями данных без копирования.

#### Возвращаемое значение

Новый `Массив` пользовательских данных. Элемент может быть равен `Неопределено`.

### Подсказки

```bsl
.Подсказки()
```

Возвращает подсказки ошибок с сохранением позиционного соответствия.

#### Возвращаемое значение

Новый `Массив` из `Строка`. Пустая строка означает отсутствие подсказки.

### URL

```bsl
.URL()
```

Возвращает URL ошибок с сохранением позиционного соответствия.

#### Возвращаемое значение

Новый `Массив` из `Строка`. Пустая строка означает отсутствие URL.

### Отобрать

```bsl
.Отобрать(<КодыОшибок>)
```

Возвращает новую выборку ошибок с одним из указанных кодов. Принимает одиночный код,
строку CSV, `Массив` или `ФиксированныйМассив`. Сравнение не учитывает регистр.

#### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| КодыОшибок | `Строка`, `Массив`, `ФиксированныйМассив` | Один или несколько машинных кодов |

#### Возвращаемое значение

Новая [`ВыборкаОшибок`](ВыборкаОшибок.md) подходящих кадров в исходном порядке.

#### Ошибки метода Отобрать

| Код | Условие |
| --- | --- |
| `argument.invalid_type` | `КодыОшибок` имеют недопустимый тип или содержат не строки |
| `argument.required` | Список кодов пуст |
| `argument.invalid_value` | Один из кодов имеет неверный формат |

### ОтобратьПоГруппе

```bsl
.ОтобратьПоГруппе(<ГруппаОшибок>)
```

Возвращает новую выборку ошибок, машинные коды которых принадлежат группе. Группа задаётся
одним или несколькими начальными сегментами кода; сравнение не учитывает регистр и выполняется
только по границе сегмента. Порядок снимков сохраняется, исходная выборка не изменяется.

#### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| ГруппаОшибок | `Строка` | Один или несколько начальных сегментов машинного кода |

#### Возвращаемое значение

Новая [`ВыборкаОшибок`](ВыборкаОшибок.md) подходящих кадров в исходном порядке.

#### Ошибки метода ОтобратьПоГруппе

| Код | Условие |
| --- | --- |
| `argument.invalid_type` | `ГруппаОшибок` не является строкой |
| `argument.invalid_value` | `ГруппаОшибок` имеет неверный формат |

### Содержит

```bsl
.Содержит(<КодОшибки>)
```

Возвращает `Истина`, если выборка содержит ошибку с указанным кодом.

#### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| КодОшибки | `Строка` | Точный машинный код |

#### Возвращаемое значение

`Булево`: `Истина`, если код найден.

#### Ошибки метода Содержит

| Код | Условие |
| --- | --- |
| `argument.invalid_type` | `КодОшибки` не является строкой |
| `argument.invalid_value` | `КодОшибки` имеет неверный формат |

### СодержитГруппу

```bsl
.СодержитГруппу(<ГруппаОшибок>)
```

Возвращает `Истина`, если выборка содержит ошибку, машинный код которой принадлежит группе.

#### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| ГруппаОшибок | `Строка` | Один или несколько начальных сегментов машинного кода |

#### Возвращаемое значение

`Булево`: `Истина`, если найдена ошибка из группы.

#### Ошибки метода СодержитГруппу

| Код | Условие |
| --- | --- |
| `argument.invalid_type` | `ГруппаОшибок` не является строкой |
| `argument.invalid_value` | `ГруппаОшибок` имеет неверный формат |

### СодержитЛюбойИз

```bsl
.СодержитЛюбойИз(<КодыОшибок>)
```

Возвращает `Истина`, если выборка содержит ошибку хотя бы с одним из указанных кодов.

#### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| КодыОшибок | `Строка`, `Массив`, `ФиксированныйМассив` | Один или несколько машинных кодов |

#### Возвращаемое значение

`Булево`: `Истина`, если найден хотя бы один код.

#### Ошибки метода СодержитЛюбойИз

| Код | Условие |
| --- | --- |
| `argument.invalid_type` | `КодыОшибок` имеют недопустимый тип или содержат не строки |
| `argument.required` | Список кодов пуст |
| `argument.invalid_value` | Один из кодов имеет неверный формат |

### ГруппыПоКоду

```bsl
.ГруппыПоКоду()
```

Группирует ошибки по нормализованному коду. Возвращает `Соответствие`, где ключ - код
ошибки в нижнем регистре, а значение - новая [`ВыборкаОшибок`](ВыборкаОшибок.md).

#### Возвращаемое значение

Новое `Соответствие`, где ключ имеет тип `Строка`, а значение - [`ВыборкаОшибок`](ВыборкаОшибок.md).
