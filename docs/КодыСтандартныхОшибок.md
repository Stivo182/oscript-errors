# КодыСтандартныхОшибок

Публичный модуль предоставляет стандартные машинные коды без строковых литералов. Все функции вызываются без
параметров и возвращают `Строка`.

## Оглавление

- [Использование](#использование)
- [Каталог кодов](#каталог-кодов)

## Использование

```bsl
Если ДиагностикаОшибок.Содержит(
    Ошибка,
    КодыСтандартныхОшибок.РесурсНеНайден()
) Тогда
    // Обработка отсутствующего ресурса
КонецЕсли;
```

## Поведение

Функции не изменяют состояние и не выбрасывают исключений. Коды стабильны и не зависят от языка сообщений.
Имена функций совпадают с именами фабрик модулей `СтандартныеОшибки` и `ПостроителиСтандартныхОшибок`.

Выбор между близкими инфраструктурными кодами описан в
[справочнике стандартных ошибок](СтандартныеОшибки.md#выбор-близких-кодов).
