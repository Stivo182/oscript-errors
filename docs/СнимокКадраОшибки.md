# СнимокКадраОшибки

Снимок одного физического кадра ошибки. Создаётся разбором, но может быть создан
напрямую. Собственные свойства снимка нельзя переназначить, однако пользовательские данные
и исходный кадр сохраняются и возвращаются по ссылке.

Название «снимок» относится к распознанным свойствам кадра и стеку вызовов. Глубокая копия
пользовательских данных не создаётся, поэтому снимок не гарантирует их неизменяемость.

## Создание

```bsl
Новый СнимокКадраОшибки(<Ошибка>)
```

**Параметры:**

| Имя | Тип | Описание |
| --- | --- | --- |
| **Ошибка** | `ИнформацияОбОшибке` | Физический кадр для создания снимка |

Для кадров, созданных самой библиотекой, снимок распознаёт вид, код, данные, подсказку и
URL. Распознаются только кадры текущей версии формата метаданных. Для остальных и внешних
кадров вид равен `ВнешняяОшибка`, а описание помещается в `Сообщение()`.

## Методы

### ИсходнаяОшибка

```bsl
ИсходнаяОшибка()
```

Возвращает по ссылке исходный физический кадр `ИнформацияОбОшибке`.

### Вид

```bsl
Вид()
```

Возвращает [`ВидыКадровОшибок`](ВидыКадровОшибок.md) кадра.

### КодОшибки

```bsl
КодОшибки()
```

Возвращает машинный код собственного кадра или пустую строку, если код отсутствует.

### ПринадлежитГруппе

```bsl
ПринадлежитГруппе(<ГруппаОшибок>)
```

Проверяет принадлежность машинного кода кадра группе ошибок. Группа задаётся одним или
несколькими начальными сегментами кода. Сравнение не учитывает регистр и выполняется только
по границе сегмента: группа `connection` включает `connection.refused`, но не включает
`connectionless.failed` или `database.connection.refused`.

Равенство полного кода и группы также считается принадлежностью. Кадр без машинного кода
не принадлежит никакой группе.

### Сообщение

```bsl
Сообщение()
```

Возвращает описание физического кадра.

### Данные

```bsl
Данные()
```

Возвращает по ссылке пользовательские данные собственного кадра или `Неопределено`.
Изменения мутабельного объекта данных после создания снимка будут видны через этот метод,
в выборках ошибок и в ранее сформированном структурированном представлении. Изменение
объекта, полученного через `Данные()`, также изменяет исходные данные кадра.

### Подсказка

```bsl
Подсказка()
```

Возвращает подсказку или пустую строку.

### URL

```bsl
URL()
```

Возвращает URL документации ошибки или пустую строку.

### МестоСоздания

```bsl
МестоСоздания()
```

Возвращает `ФиксированнаяСтруктура` с полями:

- `ИмяМодуля` — имя модуля места создания кадра или пустая строка;
- `НомерСтроки` — номер строки места создания кадра или `0`;
- `ИсходнаяСтрока` — исходная строка места создания кадра или пустая строка.

Поля структуры нельзя переназначить.

### СтекВызовов

```bsl
СтекВызовов()
```

Возвращает независимую копию стека вызовов кадра.

Для кадров, созданных guard-модулем `ПроверкаАргументов`, стек нормализуется: внутренние
кадры библиотеки удаляются, а местом создания становится первый внешний кадр.
