# Поиск всех ошибок выбранных типов

## Цель

Добавить в публичный модуль `ДиагностикаОшибок` функцию `НайтиОшибки`, которая возвращает все распознанные
ошибки одного или нескольких типов из физической цепочки. Существующие функции `НайтиОшибку` и `ЭтоОшибка`
сохраняют текущие сигнатуры и поведение.

## Публичный API

```bsl
ДиагностикаОшибок.НайтиОшибки(Ошибка, ТипыОшибок)
```

Параметры:

- `Ошибка` — `ИнформацияОбОшибке`, исследуемая ошибка;
- `ТипыОшибок` — `Строка`, один машинный тип или несколько типов, разделённых запятыми.

Возвращаемое значение — новый `Массив` исходных кадров `ИнформацияОбОшибке`. Кадры располагаются в физическом
порядке: от внешнего к корневому. Если совпадений нет, функция возвращает пустой массив.

Примеры допустимых фильтров:

```bsl
"database.timeout"
"database.timeout,network.timeout"
" database.timeout , network.timeout "
```

## Разбор и проверка фильтра

Строка разделяется по запятым. Пробелы в начале и конце каждого полученного элемента удаляются, после чего
каждый тип проверяется существующими правилами формата машинного типа ошибки.

Пустая строка, пустой элемент и элемент неверного формата считаются ошибкой входных данных. Например, должны
быть отклонены фильтры `""`, `"database.timeout,"`, `",database.timeout"` и
`"database.timeout, ,network.timeout"`. Для неверного элемента используется существующее сообщение проверки
формата типа ошибки.

Сравнение типов выполняется без учёта регистра, как в `НайтиОшибку`. Повторяющиеся типы в фильтре не приводят
к повторному добавлению одного кадра в результат.

## Обход цепочки

Функция один раз получает просмотр цепочки через `ВнутреннееУстройствоОшибок.ПросмотретьЦепочку`. Для каждого
физического кадра создаётся `СнимокКадраОшибки`.

В результат добавляются только кадры вида `ВидыКадровОшибок.Ошибка`, тип которых входит в разобранный фильтр.
Контекстные, внешние и неподдерживаемые кадры пропускаются. Все подходящие кадры добавляются без досрочного
завершения обхода, поэтому повторные вхождения одного типа сохраняются.

## Совместимость

`НайтиОшибку(Ошибка, ТипОшибки)` продолжает принимать ровно один тип и возвращать первый подходящий кадр либо
`Неопределено`. `ЭтоОшибка(Ошибка, ТипОшибки)` также продолжает принимать один тип. Передача списка через
запятую в эти функции остаётся ошибкой формата.

Новая функция не изменяет построение, представление или физический порядок цепочки ошибок.

## Проверки

Тесты публичного API должны подтвердить:

- возврат всех повторных вхождений одного типа;
- возврат всех вхождений нескольких перечисленных типов;
- сохранение физического порядка кадров независимо от порядка типов в фильтре;
- поддержку пробелов рядом с запятыми;
- сравнение без учёта регистра;
- отсутствие дубликатов из-за повторения типа в фильтре;
- возврат пустого массива при отсутствии совпадений;
- пропуск контекстных, внешних и неподдерживаемых кадров;
- отклонение пустой строки, пустых элементов и типов неверного формата;
- неизменность поведения `НайтиОшибку` и `ЭтоОшибка`.
