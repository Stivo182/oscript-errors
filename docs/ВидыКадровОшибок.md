# ВидыКадровОшибок

Модуль строковых констант видов кадра.

## Ошибка

```bsl
ВидыКадровОшибок.Ошибка()
```

Возвращает вид кадра классифицированной ошибки.

**Возвращаемое значение:**

`Строка` - значение `"Ошибка"`.

## Контекст

```bsl
ВидыКадровОшибок.Контекст()
```

Возвращает вид контекстного кадра ошибки.

**Возвращаемое значение:**

`Строка` - значение `"Контекст"`.

## ВнешняяОшибка

```bsl
ВидыКадровОшибок.ВнешняяОшибка()
```

Возвращает вид внешнего кадра, который библиотека не смогла распознать.

**Возвращаемое значение:**

`Строка` - значение `"ВнешняяОшибка"`.

Эти значения используются методом [`СнимокКадраОшибки.Вид`](СнимокКадраОшибки.md#вид)
и структурированным представлением
[`РазборОшибки.ВСтруктуру`](РазборОшибки.md#вструктуру).
