# ДиагностикаОшибок

Публичный модуль для быстрого поиска и представления ошибок. Если нужна одна операция,
используйте короткие методы модуля. Для нескольких обращений к одной цепочке сначала создайте
[`РазборОшибки`](РазборОшибки.md), чтобы не разбирать её повторно.

## Разобрать

```bsl
ДиагностикаОшибок.Разобрать(<Ошибка>)
```

**Параметры:**

| Имя | Тип | Описание |
| --- | --- | --- |
| **Ошибка** | `ИнформацияОбОшибке` | Внешний кадр разбираемой цепочки |

**Возвращаемое значение:**

`РазборОшибки` — материализованный разбор цепочки.

## Код эффективной ошибки

```bsl
Код = ДиагностикаОшибок.КодОшибки(<Ошибка>)
```

Возвращает машинный код первой классифицированной ошибки в цепочке или `Неопределено`,
если классифицированной ошибки нет.

## Проверка цепочки

```bsl
ДиагностикаОшибок.Содержит(<Ошибка>, <КодОшибки>)
ДиагностикаОшибок.СодержитЛюбойИз(<Ошибка>, <КодыОшибок>)
ДиагностикаОшибок.СодержитГруппу(<Ошибка>, <ГруппаОшибок>)
```

| Метод | Параметр поиска | Результат |
| --- | --- | --- |
| `Содержит` | Машинный код — `Строка` | `Булево` |
| `СодержитЛюбойИз` | Код, CSV-строка, `Массив` или `ФиксированныйМассив` кодов | `Булево` |
| `СодержитГруппу` | Один или несколько начальных сегментов машинного кода | `Булево` |

Все проверки просматривают классифицированные ошибки во всей физической цепочке. Сравнение
кодов и групп не зависит от регистра.

## Поиск первой ошибки

```bsl
Снимок = ДиагностикаОшибок.НайтиПервую(<Ошибка>, <КодОшибки>)
```

Возвращает первый [`СнимокКадраОшибки`](СнимокКадраОшибки.md) с указанным кодом при обходе
от внешнего кадра к корневому. Если совпадений нет, возвращает `Неопределено`.

## Представления

```bsl
Краткое = ДиагностикаОшибок.КраткоеПредставление(<Ошибка>);
Пользовательское = ДиагностикаОшибок.ПользовательскоеПредставление(<Ошибка>);
Диагностическое = ДиагностикаОшибок.ДиагностическоеПредставление(<Ошибка>);
```

- `КраткоеПредставление` возвращает компактную строку с текущим кадром и эффективной ошибкой.
- `ПользовательскоеПредставление` дополнительно выводит подсказку и URL текущего кадра.
- `ДиагностическоеПредставление` формирует полный отчёт по цепочке со стеком и данными.

Диагностическое представление предназначено для логов и отладки. Оно может раскрывать
пользовательские данные, места возникновения и стек вызовов; не передавайте в данные ошибки
пароли, токены и другие секреты.

Подробнее о составе строк см. в разделе [Представление ошибок](ПредставлениеОшибок.md).

## Примеры

```bsl
Ошибка = СтандартныеОшибки.ИстеклоВремяОжиданияСоединения("api.example.org");

Если ДиагностикаОшибок.СодержитГруппу(Ошибка, "connection") Тогда
    Сообщить(ДиагностикаОшибок.ПользовательскоеПредставление(Ошибка));
КонецЕсли;
```

Если нужны несколько результатов, разберите цепочку один раз:

```bsl
Разбор = ДиагностикаОшибок.Разобрать(Ошибка);
Код = Разбор.КодОшибки();
ЕстьТаймаут = Разбор.Ошибки().Содержит("connection.timeout");
Отчёт = Разбор.ДиагностическоеПредставление();
```
