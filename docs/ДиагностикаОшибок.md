# ДиагностикаОшибок

Публичный модуль для быстрого поиска и представления ошибок. Если нужна одна операция,
используйте короткие методы модуля. Для нескольких обращений к одной цепочке сначала создайте
[`РазборОшибки`](РазборОшибки.md), чтобы переиспользовать подготовленные им результаты.

## Общий контракт

Параметр `Ошибка` всех функций имеет тип `ИнформацияОбОшибке` и задаёт внешний кадр физической цепочки.
Функции не изменяют переданную цепочку. Поиск выполняется от внешнего кадра к непосредственным причинам.

## Разобрать

```bsl
Разбор = ДиагностикаОшибок.Разобрать(<Ошибка>);
```

**Параметры:**

| Имя | Тип | Описание |
| --- | --- | --- |
| Ошибка | `ИнформацияОбОшибке` | Внешний кадр разбираемой цепочки |

#### Возвращаемое значение

`РазборОшибки`: ленивый разбор цепочки.

## Код эффективной ошибки

```bsl
Код = ДиагностикаОшибок.КодОшибки(<Ошибка>);
```

#### Возвращаемое значение

`Строка`, `Неопределено`: машинный код первой классифицированной ошибки в цепочке или
`Неопределено`, если классифицированной ошибки нет.

## Данные эффективной ошибки

```bsl
Данные = ДиагностикаОшибок.ДанныеОшибки(<Ошибка>);
```

Поиск завершается на первой классифицированной ошибке.
Данные не копируются. Изменение полученного объекта изменяет исходные данные кадра.

#### Возвращаемое значение

`Произвольный`, `Неопределено`: пользовательские данные эффективной ошибки или `Неопределено`,
если классифицированной ошибки нет.

## Эффективная ошибка

```bsl
Снимок = ДиагностикаОшибок.ЭффективнаяОшибка(<Ошибка>);
```

Обход завершается при первой классифицированной ошибке.

#### Возвращаемое значение

`СнимокКадраОшибки`, `Неопределено`: снимок эффективной ошибки или `Неопределено`,
если классифицированной ошибки нет.

## Корневая причина

```bsl
Корень = ДиагностикаОшибок.КорневаяПричина(<Ошибка>);
```

Корнем может быть внешний неклассифицированный кадр. Для усечённой или непрочитанной цепочки
корень недоступен.

#### Возвращаемое значение

`СнимокКадраОшибки`, `Неопределено`: снимок фактической корневой причины или `Неопределено`,
если цепочка усечена или не прочитана полностью.

`ДанныеОшибки` и `ЭффективнаяОшибка` не создают полный разбор. `КорневаяПричина` просматривает
цепочку до конца, но создаёт снимок только для возвращаемого кадра.

## Проверка цепочки

```bsl
ЕстьКод = ДиагностикаОшибок.Содержит(<Ошибка>, <КодОшибки>);
ЕстьЛюбойКод = ДиагностикаОшибок.СодержитЛюбойИз(<Ошибка>, <КодыОшибок>);
ЕстьГруппа = ДиагностикаОшибок.СодержитГруппу(<Ошибка>, <ГруппаОшибок>);
```

| Метод | Параметр поиска | Результат |
| --- | --- | --- |
| `Содержит` | Машинный код - `Строка` | `Булево` |
| `СодержитЛюбойИз` | Код, CSV-строка, `Массив` или `ФиксированныйМассив` кодов | `Булево` |
| `СодержитГруппу` | Один или несколько начальных сегментов машинного кода | `Булево` |

Проверки последовательно просматривают физическую цепочку и завершаются при первом совпадении,
не создавая полный `РазборОшибки` и снимки остальных кадров. Сравнение кодов и групп не зависит
от регистра.

## Поиск первой ошибки

```bsl
Снимок = ДиагностикаОшибок.НайтиПервую(<Ошибка>, <КодОшибки>);
```

Возвращает первый [`СнимокКадраОшибки`](СнимокКадраОшибки.md) с указанным кодом при обходе
от внешнего кадра к корневому. Полноценный снимок создаётся только для найденного физического
кадра.

#### Возвращаемое значение

`СнимокКадраОшибки`, `Неопределено`: первый снимок с указанным кодом или `Неопределено`,
если совпадений нет.

## Представления

```bsl
Краткое = ДиагностикаОшибок.КраткоеПредставление(<Ошибка>);
Пользовательское = ДиагностикаОшибок.ПользовательскоеПредставление(<Ошибка>);
Диагностическое = ДиагностикаОшибок.ДиагностическоеПредставление(<Ошибка>);
```

- `КраткоеПредставление` возвращает компактную строку с текущим кадром и эффективной ошибкой.
- `ПользовательскоеПредставление` дополнительно выводит подсказку и URL текущего кадра.
- `ДиагностическоеПредставление` формирует полный отчёт по цепочке со стеком и данными.

Диагностическое представление предназначено для логов и отладки. Оно может раскрывать
пользовательские данные, места возникновения и стек вызовов; не передавайте в данные ошибки
пароли, токены и другие секреты.

Подробнее о составе строк см. в разделе [Представление ошибок](ПредставлениеОшибок.md).

## Ошибки

| Код | Условие |
| --- | --- |
| `argument.invalid_type` | Ошибка, код, список кодов или группа имеют недопустимый тип |
| `argument.required` | Список кодов пуст |
| `argument.invalid_value` | Код, элемент списка кодов или группа имеют неверный формат |

Коды доступны через [`КодыСтандартныхОшибок`](КодыСтандартныхОшибок.md).

`ДиагностическоеПредставление()` устойчиво к ошибкам представления пользовательских данных: сбойное значение
заменяется безопасным диагностическим текстом и не скрывает исходную цепочку.

## Примеры

```bsl
Ошибка = СтандартныеОшибки.ИстеклоВремяОжиданияСоединения("api.example.org");

Если ДиагностикаОшибок.СодержитГруппу(Ошибка, "connection") Тогда
    Сообщить(ДиагностикаОшибок.ПользовательскоеПредставление(Ошибка));
КонецЕсли;
```

Если нужны несколько результатов, разберите цепочку один раз:

```bsl
Разбор = ДиагностикаОшибок.Разобрать(Ошибка);
Код = Разбор.КодОшибки();
ЕстьТаймаут = Разбор.Ошибки().Содержит("connection.timeout");
Отчёт = Разбор.ДиагностическоеПредставление();
```
