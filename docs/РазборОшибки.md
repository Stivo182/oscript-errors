# РазборОшибки

Ленивый разбор физической цепочки ошибки. Создаётся через
[`ДиагностикаОшибок.Разобрать`](ДиагностикаОшибок.md).

При создании разбор проверяет и сохраняет исходную ошибку. Физическая цепочка и снимки кадров
фиксируются при первой операции, которой нужен полный разбор. Пользовательские данные кадров
сохраняются по ссылке и могут изменяться владельцем исходного объекта.

## Создание

```bsl
Новый РазборОшибки(<Ошибка>)
```

**Параметры:**

| Имя | Тип | Описание |
| --- | --- | --- |
| **Ошибка** | `ИнформацияОбОшибке` | Внешний кадр разбираемой цепочки |

Полный разбор просматривает не более 64 физических кадров.

#### Возвращаемое значение

Новый ленивый [`РазборОшибки`](РазборОшибки.md).

#### Ошибки конструктора

| Код | Условие |
| --- | --- |
| `argument.invalid_type` | `Ошибка` не имеет тип `ИнформацияОбОшибке` |

## Методы

### Снимки

```bsl
.Снимки()
```

Возвращает все просмотренные физические кадры в виде независимой копии массива
[`СнимокКадраОшибки`](СнимокКадраОшибки.md).

#### Возвращаемое значение

Новый `Массив` из [`СнимокКадраОшибки`](СнимокКадраОшибки.md) в физическом порядке.

### Ошибки

```bsl
.Ошибки()
```

Возвращает [`ВыборкаОшибок`](ВыборкаОшибок.md) всех распознанных классифицированных
кадров.

#### Возвращаемое значение

[`ВыборкаОшибок`](ВыборкаОшибок.md) с неизменяемым составом.

### Контексты

```bsl
.Контексты()
```

Возвращает независимую копию распознанных контекстных кадров.

#### Возвращаемое значение

Новый `Массив` из [`СнимокКадраОшибки`](СнимокКадраОшибки.md) в физическом порядке.

### ЭффективнаяОшибка

```bsl
.ЭффективнаяОшибка()
```

Возвращает первую распознанную ошибку или `Неопределено`.

#### Возвращаемое значение

[`СнимокКадраОшибки`](СнимокКадраОшибки.md) или `Неопределено`, если классифицированной ошибки нет.

### ПоследнийКадр

```bsl
.ПоследнийКадр()
```

Возвращает снимок последнего просмотренного физического кадра.

#### Возвращаемое значение

[`СнимокКадраОшибки`](СнимокКадраОшибки.md): последний доступный кадр.

### КорневаяПричина

```bsl
.КорневаяПричина()
```

Возвращает снимок фактической корневой причины полностью просмотренной цепочки. Для
усечённой цепочки возвращает `Неопределено`.

#### Возвращаемое значение

[`СнимокКадраОшибки`](СнимокКадраОшибки.md) или `Неопределено` для усечённой цепочки.

### ЦепочкаУсечена

```bsl
.ЦепочкаУсечена()
```

Возвращает `Истина`, если есть непросмотренная причина.

#### Возвращаемое значение

`Булево`: признак усечения физической цепочки.

### КодОшибки

```bsl
.КодОшибки()
```

Возвращает машинный код эффективной ошибки или `Неопределено`.

#### Возвращаемое значение

`Строка` или `Неопределено`, если классифицированной ошибки нет.

### Данные

```bsl
.Данные()
```

Возвращает пользовательские данные эффективной ошибки.

#### Возвращаемое значение

Произвольный или `Неопределено`. Данные возвращаются без копирования.

### Подсказка

```bsl
.Подсказка()
```

Возвращает первую непустую подсказку распознанной ошибки или пустую строку.

#### Возвращаемое значение

`Строка`: подсказка или пустая строка.

### URL

```bsl
.URL()
```

Возвращает первый непустой URL распознанной ошибки или пустую строку.

#### Возвращаемое значение

`Строка`: URL или пустая строка.

### КраткоеПредставление

```bsl
.КраткоеПредставление()
```

Возвращает код и сообщение текущей ошибки. Для текущего контекста или внешней обёртки возвращает
их сообщение вместе с кодом и сообщением эффективной ошибки, не включая промежуточные кадры.

#### Возвращаемое значение

`Строка`: краткое человекочитаемое представление.

### ПользовательскоеПредставление

```bsl
.ПользовательскоеПредставление()
```

Возвращает краткое представление текущего кадра, его подсказку и URL. Если текущий кадр - контекст
или внешняя обёртка, краткая строка также содержит код и сообщение эффективной ошибки.

#### Возвращаемое значение

`Строка`: пользовательское представление с подсказкой и URL текущего кадра.

### ДиагностическоеПредставление

```bsl
.ДиагностическоеПредставление()
```

Возвращает полный диагностический отчёт с данными, всей цепочкой причин и стеком вызовов.

#### Возвращаемое значение

`Строка`: диагностическое представление для журналирования и отладки.

### ВСтруктуру

```bsl
.ВСтруктуру()
```

Возвращает структурированное представление просмотренной цепочки: `Цепочка`,
`ЭффективнаяОшибка`, `ЦепочкаУсечена` и `Стек`. Подробнее см. в
[`ПредставлениеОшибок`](ПредставлениеОшибок.md).

`Цепочка` содержит структуры кадров с полями `Вид`, `КодОшибки`, `Сообщение`, `Данные`, `Подсказка`, `URL`,
`ИмяМодуля`, `НомерСтроки` и `ИсходнаяСтрока`. `ЭффективнаяОшибка` содержит тот же объект структуры, что и первый
классифицированный элемент `Цепочки`, либо `Неопределено`. `Стек` содержит структуры с полями `ИмяМодуля` и
`НомерСтроки`. Массивы и структуры оболочки создаются заново, но пользовательские данные сохраняются по ссылке.

#### Возвращаемое значение

Новая `Структура` с полями `Цепочка`, `ЭффективнаяОшибка`, `ЦепочкаУсечена` и `Стек`.

## Устойчивость представлений

Ошибки представления пользовательских значений не прерывают диагностический отчёт: вместо сбойного значения
используется безопасный диагностический текст.
