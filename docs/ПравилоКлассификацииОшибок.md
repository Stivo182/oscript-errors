# ПравилоКлассификацииОшибок

Описывает, как распознать неструктурированную ошибку и присвоить ей стабильный код.
[`КлассификаторОшибок`](КлассификаторОшибок.md) применяет условия правила к каждому
доступному кадру цепочки ошибки.

## Создание

```bsl
Правило = Новый ПравилоКлассификацииОшибок;
```

После создания задайте условия сопоставления, метаданные и результат. В примерах
`КлассифицируетКак()` указан последним, чтобы определение читалось от условий к результату.

Для нативной ошибки все текстовые условия - `СовпадаетС()`, `НачинаетсяС()`,
`Содержит()` и `ОканчиваетсяНа()` - проверяют внутреннее сообщение без служебной
обёртки `External exception (...)`. `СНативнымТипом()` остаётся отдельным условием
для типа .NET.

## Методы

### СовпадаетС

```bsl
.СовпадаетС(<ИсходноеСообщение>)
```

Задаёт точное сообщение ошибки. Его можно сочетать только с `СНативнымТипом()`.

Например, для `External exception (System.IO.IOException): Файл уже существует`
сопоставляется `Файл уже существует`.

#### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| ИсходноеСообщение | `Строка` | Полное сообщение или шаблон `НСтр` |

#### Возвращаемое значение

`ПравилоКлассификацииОшибок`: это правило.

### СНативнымТипом

```bsl
.СНативнымТипом(<НативныйТип>)
```

Ограничивает правило полным именем типа .NET. Используйте его, когда одинаковый текст
может относиться к разным причинам ошибки.

#### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| НативныйТип | `Строка` | Полное имя типа .NET, например `System.IO.IOException` |

#### Возвращаемое значение

`ПравилоКлассификацииОшибок`: это правило.

### НачинаетсяС

```bsl
.НачинаетсяС(<Префикс>)
```

Задаёт начало сообщения. Для текстового правила без `СНативнымТипом()` префикс обязателен.

#### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| Префикс | `Строка` | Начальная часть сообщения или шаблон `НСтр` |

#### Возвращаемое значение

`ПравилоКлассификацииОшибок`: это правило.

### Содержит

```bsl
.Содержит(<Фрагмент>)
```

Требует наличия фрагмента в сообщении. Применяйте его вместе с префиксом или нативным
типом, чтобы не сопоставить постороннюю ошибку.

#### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| Фрагмент | `Строка` | Часть сообщения или шаблон `НСтр` |

#### Возвращаемое значение

`ПравилоКлассификацииОшибок`: это правило.

### ОканчиваетсяНа

```bsl
.ОканчиваетсяНа(<Окончание>)
```

Требует указанное окончание сообщения.

#### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| Окончание | `Строка` | Конечная часть сообщения или шаблон `НСтр` |

#### Возвращаемое значение

`ПравилоКлассификацииОшибок`: это правило.

### СПриоритетом

```bsl
.СПриоритетом(<Приоритет>)
```

Задаёт приоритет для выбора между совпадениями одинаковой силы. Большее значение имеет
преимущество. Не используйте приоритет для замены более точного условия.

#### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| Приоритет | `Число` | Приоритет правила |

#### Возвращаемое значение

`ПравилоКлассификацииОшибок`: это правило.

### СИдентификатором

```bsl
.СИдентификатором(<Идентификатор>)
```

Задаёт стабильное имя правила. Классификатор сохраняет его в поле `Правило`
диагностических данных результата. Если идентификатор не задан, классификатор создаёт его
автоматически.

#### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| Идентификатор | `Строка` | Стабильное имя правила |

#### Возвращаемое значение

`ПравилоКлассификацииОшибок`: это правило.

### КлассифицируетКак

```bsl
.КлассифицируетКак(<КодОшибки>, <ОписаниеОшибки>)
```

Задаёт обязательные код и описание результата. Положение метода в цепочке не влияет на
сопоставление. Правило без результата классификатор не зарегистрирует.

#### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| КодОшибки | `Строка` | Стабильный машинный код результата |
| ОписаниеОшибки | `Строка` | Описание результата или шаблон `НСтр` |

#### Возвращаемое значение

`ПравилоКлассификацииОшибок`: это правило.

### НативныйТип

```bsl
.НативныйТип()
```

Возвращает заданный .NET-тип или пустую строку.

#### Возвращаемое значение

`Строка`: полное имя .NET-типа или пустая строка.

### ИсходноеСообщение

```bsl
.ИсходноеСообщение()
```

#### Возвращаемое значение

`Строка`: точное сообщение, шаблон `НСтр` или пустая строка.

### Префикс


Возвращает сообщение, заданное методом `НачинаетсяС()`.

#### Возвращаемое значение

`Строка`: префикс, шаблон `НСтр` или пустая строка.

### Фрагмент


Возвращает сообщение, заданное методом `Содержит()`.

#### Возвращаемое значение

`Строка`: фрагмент, шаблон `НСтр` или пустая строка.

### Окончание


Возвращает сообщение, заданное методом `ОканчиваетсяНа()`.

#### Возвращаемое значение

### КодОшибки

```bsl

```

Возвращает код результата классификации.

#### Возвращаемое значение

`Строка`: код ошибки или пустая строка.

### ОписаниеРезультата

```bsl
.ОписаниеРезультата()
```

Возвращает описание результата классификации.

#### Возвращаемое значение

`Строка`: описание, шаблон `НСтр` или пустая строка.

### Идентификатор

```bsl
.Идентификатор()
```

Возвращает явно заданный идентификатор правила.

#### Возвращаемое значение

`Строка`: идентификатор или пустая строка.

### Приоритет

```bsl
.Приоритет()
```

Возвращает приоритет правила.

#### Возвращаемое значение

`Число`: приоритет правила.

## Практический пример

Внешнее исключение содержит изменяемый путь файла, но его тип и постоянные части текста
позволяют уверенно определить причину. Правило сначала описывает эти условия, а затем
задаёт код и описание результата:

```bsl
Правило = Новый ПравилоКлассификацииОшибок
    .СНативнымТипом("System.IO.IOException")
    .НачинаетсяС("ru = 'Файл '''; en = 'The file '''")
    .ОканчиваетсяНа("ru = ''' уже существует.'; en = ''' already exists.'")
    .СИдентификатором("filesystem.already_exists.file_path")
    .КлассифицируетКак(
        "filesystem.already_exists",
        "ru = 'Файл уже существует'; en = 'File already exists'"
    );
```

Для сообщения `External exception (System.IO.IOException): Файл 'report.json' уже
существует.` правило сопоставит тип `System.IO.IOException`, префикс и окончание, после
чего вернёт код `filesystem.already_exists`. Путь между ними в условие не входит.

## Локализованные шаблоны

Сообщение, префикс, фрагмент, окончание и описание могут быть обычной строкой или
шаблоном `НСтр` с вариантами `ru` и `en`. Обычная строка доступна для обоих языков.
Условия одного совпадения берутся из одного языка: русский префикс не объединяется с
английским окончанием.
