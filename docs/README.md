# Документация API

Документация по публичному API пакета `errors`. Пакет создаёт структурированные цепочки ошибок, сохраняет контекст
операций и предоставляет средства для программного анализа и формирования представлений.

## Руководства

- [Создание ошибок](СозданиеОшибок.md)
- [Поиск в цепочке](ПоискВЦепочке.md)
- [Представление ошибок](ПредставлениеОшибок.md)

## Классы

- [ПостроительОшибки](ПостроительОшибки.md) - поэтапная настройка одного кадра
- [РазборОшибки](РазборОшибки.md) - разбор физической цепочки и представления
- [СнимокКадраОшибки](СнимокКадраОшибки.md) - снимок кадра
- [ВыборкаОшибок](ВыборкаОшибок.md) - выборка и группировка ошибок

## Модули

- [ФабрикаОшибок](ФабрикаОшибок.md) - универсальное создание ошибок
- [СтандартныеОшибки](СтандартныеОшибки.md) - готовые стандартные ошибки
- [КодыСтандартныхОшибок](КодыСтандартныхОшибок.md) - именованные стандартные машинные коды
- [ПостроителиСтандартныхОшибок](ПостроителиСтандартныхОшибок.md) - обогащаемые стандартные ошибки
- [ПроверкаАргументов](ПроверкаАргументов.md) - проверки входных параметров
- [ДиагностикаОшибок](ДиагностикаОшибок.md) - быстрый поиск, разбор и представление ошибок
- [ВидыКадровОшибок](ВидыКадровОшибок.md) - строковые виды кадров
