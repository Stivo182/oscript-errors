# ПостроительОшибки

Fluent-построитель одного кадра ошибки. Произвольный построитель создаётся напрямую,
стандартный - через `ПостроителиСтандартныхОшибок`.

## Создание

```bsl
Новый ПостроительОшибки(
    <КодОшибки> = Неопределено,
    <Сообщение> = "",
    <Вид> = Неопределено
)
```

**Параметры:**

| Имя | Тип | Описание |
| --- | --- | --- |
| КодОшибки | `Строка`, `Неопределено` | Стабильный машинный код; для контекстного кадра должен быть `Неопределено` |
| Сообщение | `Строка` | Человекочитаемое описание |
| Вид | `Строка`, `Неопределено` | `ВидыКадровОшибок.Ошибка()` или `ВидыКадровОшибок.Контекст()` |

По умолчанию создаётся кадр вида `Ошибка`.

Для кадра вида `Контекст` причина обязательна, `КодОшибки` должен быть равен
`Неопределено`, а `Подсказка` и `URL` - пустым строкам. Несогласованный набор полей
приведёт к структурированному исключению при вызове `Построить()`.

#### Возвращаемое значение

Новый [`ПостроительОшибки`](ПостроительОшибки.md). Конструктор сохраняет поля без проверки; их контракт проверяет
`Построить()`.

## Методы

Все методы, кроме `Построить()`, возвращают `ЭтотОбъект` и предназначены для цепочек
вызовов.

### КодОшибки

```bsl
.КодОшибки(<Значение>)
```

Устанавливает стабильный машинный код.

Код содержит минимум два разделённых точками сегмента. Сегмент начинается с буквы и может содержать буквы,
цифры и `_`.

#### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| Значение | `Строка`, `Неопределено` | Код классифицированной ошибки или отсутствие кода у контекста |

#### Возвращаемое значение

Этот [`ПостроительОшибки`](ПостроительОшибки.md).

### Сообщение

```bsl
.Сообщение(<Значение>)
```

Устанавливает человекочитаемое описание.

#### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| Значение | `Строка` | Непустое описание кадра |

#### Возвращаемое значение

Этот [`ПостроительОшибки`](ПостроительОшибки.md).

### Данные

```bsl
.Данные(<Ключ>, <Значение>)
```

Добавляет поле структурированных данных. Повторный ключ заменяет ранее установленное
значение. Нельзя использовать вместе с `ПроизвольныеДанные()`.

#### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| Ключ | `Строка` | Непустое допустимое имя поля `Структура` |
| Значение | Произвольный | Значение поля данных |

#### Возвращаемое значение

Этот [`ПостроительОшибки`](ПостроительОшибки.md).

#### Ошибки метода Данные

| Код | Условие |
| --- | --- |
| `argument.invalid_type` | `Ключ` не является строкой |
| `argument.required` | `Ключ` является пустой строкой |
| `argument.invalid_value` | `Ключ` нельзя использовать как имя поля `Структура` |
| `operation.invalid_state` | Ранее был вызван `ПроизвольныеДанные()` |

### ПроизвольныеДанные

```bsl
.ПроизвольныеДанные(<Значение>)
```

Устанавливает произвольное значение данных. Значение передаётся по ссылке. Нельзя
использовать вместе с `Данные()`.

#### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| Значение | Произвольный | Связанные с ошибкой данные |

#### Возвращаемое значение

Этот [`ПостроительОшибки`](ПостроительОшибки.md).

#### Ошибки метода ПроизвольныеДанные

| Код | Условие |
| --- | --- |
| `operation.invalid_state` | Ранее был вызван `Данные()` |

### Подсказка

```bsl
.Подсказка(<Значение>)
```

Устанавливает подсказку по исправлению ошибки.

#### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| Значение | `Строка` | Подсказка или пустая строка |

#### Возвращаемое значение

Этот [`ПостроительОшибки`](ПостроительОшибки.md).

### URL

```bsl
.URL(<Значение>)
```

Устанавливает адрес страницы с дополнительной информацией об ошибке. Проверяется только
строковый тип, сам адрес не разбирается.

#### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| Значение | `Строка` | URL документации или пустая строка |

#### Возвращаемое значение

Этот [`ПостроительОшибки`](ПостроительОшибки.md).

### Причина

```bsl
.Причина(<Значение>)
```

Устанавливает непосредственную причину кадра: `ИнформацияОбОшибке` или `Неопределено`.

#### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| Значение | `ИнформацияОбОшибке`, `Неопределено` | Непосредственная причина кадра |

#### Возвращаемое значение

Этот [`ПостроительОшибки`](ПостроительОшибки.md).

### Построить

```bsl
.Построить()
```

Создаёт настроенный кадр `ИнформацияОбОшибке`. В `Описание` записывается пользовательское
представление текущего кадра без данных, стека вызовов и исходной строки. Для контекста оно
также содержит код и сообщение эффективной ошибки, но не промежуточные контексты.

#### Возвращаемое значение

Новая `ИнформацияОбОшибке`, совместимая с `ВызватьИсключение`.

#### Ошибки метода Построить

| Код | Условие |
| --- | --- |
| `argument.invalid_type` | Поле или причина имеют недопустимый тип |
| `argument.required` | Сообщение или причина контекстного кадра не заполнены |
| `argument.invalid_value` | Код, вид или набор полей контекстного кадра недопустимы |

Структурированные данные копируются при построении, но вложенные объекты сохраняются по ссылке.
Произвольные данные всегда сохраняются по ссылке. Изменение построителя не меняет ранее созданную ошибку.
