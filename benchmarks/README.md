# Бенчмарки errors

Каталог содержит бенчмарки основных сценариев библиотеки: создания ошибок, работы с цепочками причин и
формирования представлений.

## Состав

- [Создание и обёртывание ошибок](БенчмаркСозданияИОбертыванияОшибок.os)
- [Создание с форматированием описания](БенчмаркСозданияОшибокСФорматированием.os)
- [Разбор и поиск по цепочке](БенчмаркРазбораИПоискаОшибок.os)
- [Формирование представлений](БенчмаркПредставленияОшибок.os)

## Запуск

Установите зависимости разработки:

```console
opm install -l --dev
```

Установите CLI BenchmarkOneScript глобально, чтобы команда `benchos` была доступна через `PATH`:

```console
opm install benchmark
```

Запустите весь набор:

```console
benchos run benchmarks
```

Для запуска отдельного бенчмарка передайте путь к его файлу:

```console
benchos run benchmarks/БенчмаркСозданияИОбертыванияОшибок.os
```

Постоянный набор выполняет 20 измерительных итераций после 6 прогревов. Минимальная длительность каждой итерации
составляет 250 мс. Для оценки изменения производительности выполните три запуска в одинаковом окружении и сравните
медианы результатов. JSON-отчёты сохраняйте в игнорируемом каталоге `out/`.

Бенчмарк поиска содержит материализованный контроль через `ДиагностикаОшибок.Разобрать`. Он позволяет сравнивать
потоковый и полный обход в рамках одного запуска независимо от абсолютной производительности машины.
