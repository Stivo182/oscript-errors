# РазборОшибки

Материализованный разбор физической цепочки ошибки. Создаётся через
[`ДиагностикаОшибок.Разобрать`](ДиагностикаОшибок.md).

Состав и свойства кадров фиксируются при создании разбора, но пользовательские данные
кадров сохраняются по ссылке и могут изменяться владельцем исходного объекта.

## Создание

```bsl
Новый РазборОшибки(<Ошибка>)
```

**Параметры:**

| Имя | Тип | Описание |
| --- | --- | --- |
| **Ошибка** | `ИнформацияОбОшибке` | Внешний кадр разбираемой цепочки |

При создании разбор просматривает не более 64 физических кадров.

## Цепочка

### Снимки

```bsl
Снимки()
```

Возвращает все просмотренные физические кадры в виде независимой копии массива
[`СнимокКадраОшибки`](СнимокКадраОшибки.md).

### Ошибки

```bsl
Ошибки()
```

Возвращает [`ВыборкаОшибок`](ВыборкаОшибок.md) всех распознанных классифицированных
кадров.

### Контексты

```bsl
Контексты()
```

Возвращает независимую копию распознанных контекстных кадров.

### ЭффективнаяОшибка

```bsl
ЭффективнаяОшибка()
```

Возвращает первую распознанную ошибку или `Неопределено`.

### ПоследнийКадр

```bsl
ПоследнийКадр()
```

Возвращает последний просмотренный физический кадр.

### КорневаяПричина

```bsl
КорневаяПричина()
```

Возвращает фактическую корневую причину полностью просмотренной цепочки. Для усечённой
цепочки возвращает `Неопределено`.

### ЦепочкаУсечена

```bsl
ЦепочкаУсечена()
```

Возвращает `Истина`, если есть непросмотренная причина.

## Данные эффективной ошибки

### КодОшибки

```bsl
КодОшибки()
```

Возвращает машинный код эффективной ошибки или `Неопределено`.

### Данные

```bsl
Данные()
```

Возвращает пользовательские данные эффективной ошибки.

### Подсказка

```bsl
Подсказка()
```

Возвращает первую непустую подсказку распознанной ошибки или пустую строку.

### URL

```bsl
URL()
```

Возвращает первый непустой URL распознанной ошибки или пустую строку.

## Представления

### КраткоеПредставление

```bsl
КраткоеПредставление()
```

Возвращает код и сообщение текущей ошибки. Для текущего контекста или внешней обёртки возвращает
их сообщение вместе с кодом и сообщением эффективной ошибки, не включая промежуточные кадры.

### ПользовательскоеПредставление

```bsl
ПользовательскоеПредставление()
```

Возвращает краткое представление текущего кадра, его подсказку и URL. Если текущий кадр — контекст
или внешняя обёртка, краткая строка также содержит код и сообщение эффективной ошибки.

### ДиагностическоеПредставление

```bsl
ДиагностическоеПредставление()
```

Возвращает полный диагностический отчёт с данными, всей цепочкой причин и стеком вызовов.

### ВСтруктуру

```bsl
ВСтруктуру()
```

Возвращает структурированное представление просмотренной цепочки: `Цепочка`,
`ЭффективнаяОшибка`, `ЦепочкаУсечена` и `Стек`. Подробнее см. в
[`ПредставлениеОшибок`](ПредставлениеОшибок.md).
