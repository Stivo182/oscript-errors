# Примеры запуска

Примеры подключают библиотеку как установленный пакет:

```bsl
#Использовать errors
```

## Подготовка

Из корня репозитория установите зависимости, соберите пакет и установите его:

```console
opm install -l --dev
opm build .
opm install -f errors-0.1.0.ospx
```

## Точечные примеры

Каждый сценарий показывает одну возможность API и не выполняет внешних операций.

| Возможность | Сценарий | Запуск |
|---|---|---|
| Создание, выброс и исследование ошибки | `СозданиеОшибки.os` | `oscript samples/СозданиеОшибки.os` |
| Контекст и оборачивание | `КонтекстИОбертывание.os` | `oscript samples/КонтекстИОбертывание.os` |
| Fluent-конструктор | `КонструкторОшибки.os` | `oscript samples/КонструкторОшибки.os` |
| Guard-проверки аргументов | `ПроверкаАргументов.os` | `oscript samples/ПроверкаАргументов.os` |
| Фабрики ошибок аргументов | `ФабрикиОшибокАргументов.os` | `oscript samples/ФабрикиОшибокАргументов.os` |
| Исследование полной цепочки | `ИсследованиеЦепочки.os` | `oscript samples/ИсследованиеЦепочки.os` |
| Поиск причины | `ПоискВЦепочке.os` | `oscript samples/ПоискВЦепочке.os` |
| Выборка нескольких типов | `ВыборкаОшибок.os` | `oscript samples/ВыборкаОшибок.os` |
| Текстовые представления | `ПредставлениеОшибки.os` | `oscript samples/ПредставлениеОшибки.os` |

## Совместное применение API

`ОбработкаОшибкиКонфигурации.os` читает `data/application.json` с намеренно неверным портом `"eighty"`. Пример
показывает классификацию настоящей ошибки преобразования, добавление контекста, оборачивание на границе приложения,
поиск причины и подробное представление.

```console
oscript samples/ОбработкаОшибкиКонфигурации.os
```

Все сценарии завершаются с кодом `0`: точечные примеры не выбрасывают исключения, а расширенный перехватывает
ожидаемую ошибку конфигурации.
