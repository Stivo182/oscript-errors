# ВидыКадровОшибок

Публичный модуль предоставляет строковые значения видов кадров ошибки. Все функции вызываются без параметров и
возвращают `Строка`.

## Оглавление

- [Использование](#использование)
- [Каталог видов](#каталог-видов)

## Использование

```bsl
Снимок = ДиагностикаОшибок.ЭффективнаяОшибка(Ошибка);
Если Снимок.Вид() = ВидыКадровОшибок.Ошибка() Тогда
    Сообщить(Снимок.КодОшибки());
КонецЕсли;
```

## Каталог видов

Общая сигнатура функций:

```bsl
ВидКадра = ВидыКадровОшибок.<ИмяВида>();
```

| Функция | Возвращаемое значение | Назначение |
| --- | --- | --- |
| `Ошибка()` | `"Ошибка"` | Классифицированная ошибка с машинным кодом |
| `Контекст()` | `"Контекст"` | Контекст выполнения без новой классификации |
| `ВнешняяОшибка()` | `"ВнешняяОшибка"` | Кадр, который библиотека не смогла распознать |

## Поведение

Функции не принимают параметров, не изменяют состояние и не выбрасывают исключений. Возвращаемые строки можно
сравнивать со значением метода `Вид()` класса `СнимокКадраОшибки` и с полем `Вид` структурированного представления.

Контекстный кадр сохраняет классификацию ближайшей причины. Внешний кадр не имеет гарантированного машинного кода.
