# КодыСтандартныхОшибок

Модуль предоставляет стандартные машинные коды без строковых литералов. Имена функций совпадают с именами фабрик
модулей [`СтандартныеОшибки`](СтандартныеОшибки.md) и `ПостроителиСтандартныхОшибок`.

## Использование

```bsl
КодОшибки = КодыСтандартныхОшибок.РесурсНеНайден();

Если Разбор.Ошибки().Содержит(КодОшибки) Тогда
    // Обработка отсутствующего ресурса
КонецЕсли;
```

Каждая функция вызывается без параметров и возвращает строковый код. Полный набор функций и соответствующих значений
приведён в [каталоге стандартных ошибок](СтандартныеОшибки.md#именованные-фабрики).
