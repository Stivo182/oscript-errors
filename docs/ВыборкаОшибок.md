# ВыборкаОшибок

Выборка классифицированных ошибок с неизменяемым составом. Получается через
[`РазборОшибки.Ошибки`](РазборОшибки.md#ошибки), методы отбора другой выборки или создаётся напрямую.

Неизменяемость относится только к составу и порядку снимков. Пользовательские данные
снимков не копируются и сохраняются по ссылке: изменение исходного мутабельного объекта
будет видно через выборку.

## Создание

```bsl
Новый ВыборкаОшибок(<Снимки>)
```

**Параметры:**

| Имя | Тип | Описание |
| --- | --- | --- |
| **Снимки** | `Массив` из `СнимокКадраОшибки` | Кадры ошибок в физическом порядке |

Выборка принимает только снимки вида `Ошибка`.

## Методы

### Снимки

```bsl
Снимки()
```

Возвращает независимую копию всех снимков в физическом порядке.

### Первая

```bsl
Первая()
```

Возвращает первый снимок или `Неопределено` для пустой выборки.

### Последняя

```bsl
Последняя()
```

Возвращает последний снимок или `Неопределено` для пустой выборки.

### Количество

```bsl
Количество()
```

Возвращает количество снимков.

### ЕстьОшибки

```bsl
ЕстьОшибки()
```

Возвращает `Истина`, если выборка не пуста.

### Коды

```bsl
Коды()
```

Возвращает коды ошибок с сохранением порядка и повторов.

### Данные

```bsl
Данные()
```

Возвращает данные ошибок с сохранением позиционного соответствия. Сам массив результата
создаётся заново, но его элементы являются исходными значениями данных без копирования.

### Подсказки

```bsl
Подсказки()
```

Возвращает подсказки ошибок с сохранением позиционного соответствия.

### URL

```bsl
URL()
```

Возвращает URL ошибок с сохранением позиционного соответствия.

### Отобрать

```bsl
Отобрать(<КодыОшибок>)
```

Возвращает новую выборку ошибок с одним из указанных кодов. Принимает одиночный код,
строку CSV, `Массив` или `ФиксированныйМассив`. Сравнение не учитывает регистр.

### ОтобратьПоГруппе

```bsl
ОтобратьПоГруппе(<ГруппаОшибок>)
```

Возвращает новую выборку ошибок, машинные коды которых принадлежат группе. Группа задаётся
одним или несколькими начальными сегментами кода; сравнение не учитывает регистр и выполняется
только по границе сегмента. Порядок снимков сохраняется, исходная выборка не изменяется.

### Содержит

```bsl
Содержит(<КодОшибки>)
```

Возвращает `Истина`, если выборка содержит ошибку с указанным кодом.

### СодержитГруппу

```bsl
СодержитГруппу(<ГруппаОшибок>)
```

Возвращает `Истина`, если выборка содержит ошибку, машинный код которой принадлежит группе.

### СодержитЛюбойИз

```bsl
СодержитЛюбойИз(<КодыОшибок>)
```

Возвращает `Истина`, если выборка содержит ошибку хотя бы с одним из указанных кодов.

### ГруппыПоКоду

```bsl
ГруппыПоКоду()
```

Группирует ошибки по нормализованному коду. Возвращает `Соответствие`, где ключ — код
ошибки в нижнем регистре, а значение — новая [`ВыборкаОшибок`](ВыборкаОшибок.md).
