# ПроверкаАргументов

Guard-модуль для проверки входных параметров. Успешные проверки ничего не возвращают;
при нарушении контракта выбрасывается структурированная ошибка.

## Общий контракт

`ИмяАргумента` должно быть непустой строкой. Необязательное `Сообщение` должно быть строкой. Пустое сообщение
заменяется стандартным локализованным текстом. Пользовательское сообщение сохраняется без изменений.

При успешной проверке процедура не возвращает значения. При нарушении проверяемого условия она выбрасывает
`ИнформацияОбОшибке`, пригодную для обработки средствами `ДиагностикаОшибок`.

## ПроверитьТип

```bsl
ПроверкаАргументов.ПроверитьТип(
    <ИмяАргумента>, <Значение>, <ДопустимыеТипы>, <Сообщение> = ""
)
```

Проверяет тип аргумента и выбрасывает ошибку при нарушении контракта.

**Параметры:**

| Имя | Тип и значение по умолчанию | Описание |
| --- | --- | --- |
| ИмяАргумента | `Строка` | Имя проверяемого аргумента. |
| Значение | `Произвольный` | Проверяемое значение. |
| ДопустимыеТипы | См. ниже | Допустимые типы значения. |
| Сообщение | `Строка = ""` | Необязательное описание ошибки. |

`ДопустимыеТипы` принимает `Тип`, `ОписаниеТипов`, строку с именами типов через запятую, `Массив` или
`ФиксированныйМассив` из значений `Тип` либо строковых имён типов.

**Возвращаемое значение:**

Не возвращает значения.

При несовпадении типа выбрасывает `argument.invalid_type`. В данных ошибки сохраняются `ИмяАргумента`,
`ОжидаемыйТип` и строковое имя фактического типа. Само фактическое значение не сохраняется.

## ПроверитьЗаполненность

```bsl
ПроверкаАргументов.ПроверитьЗаполненность(
    <ИмяАргумента>, <Значение>, <Сообщение> = ""
)
```

Проверяет заполненность аргумента и выбрасывает ошибку при нарушении контракта.

**Параметры:**

| Имя | Тип и значение по умолчанию | Описание |
| --- | --- | --- |
| ИмяАргумента | `Строка` | Имя проверяемого аргумента. |
| Значение | `Произвольный` | Проверяемое значение. |
| Сообщение | `Строка = ""` | Необязательное описание ошибки. |

Если тип не поддерживает проверку заполненности, проверка считается пройденной.

**Возвращаемое значение:**

Не возвращает значения.

При незаполненном значении выбрасывает `argument.required`. В данных сохраняется только `ИмяАргумента`.

## ПроверитьДопустимость

```bsl
ПроверкаАргументов.ПроверитьДопустимость(
    <ИмяАргумента>, <Допустимо>, <Ожидание>, <Сообщение> = ""
)
```

Проверяет допустимость аргумента и выбрасывает ошибку при нарушении контракта.

**Параметры:**

| Имя | Тип и значение по умолчанию | Описание |
| --- | --- | --- |
| ИмяАргумента | `Строка` | Имя проверяемого аргумента. |
| Допустимо | `Булево` | Результат проверки допустимости. |
| Ожидание | `Строка` | Описание допустимого значения или ограничения. |
| Сообщение | `Строка = ""` | Необязательное описание ошибки. |

**Возвращаемое значение:**

Не возвращает значения.

Если `Допустимо = Ложь`, выбрасывает `argument.invalid_value`. В данных сохраняются `ИмяАргумента` и `Ожидание`.

## ПроверитьРавенство

```bsl
ПроверкаАргументов.ПроверитьРавенство(
    <ИмяАргумента>, <Значение>, <ОжидаемоеЗначение>, <Сообщение> = ""
)
```

Проверяет равенство аргумента ожидаемому значению.

**Параметры:**

| Имя | Тип и значение по умолчанию | Описание |
| --- | --- | --- |
| ИмяАргумента | `Строка` | Имя проверяемого аргумента. |
| Значение | `Произвольный` | Проверяемое значение. |
| ОжидаемоеЗначение | `Произвольный` | Ожидаемое значение аргумента. |
| Сообщение | `Строка = ""` | Необязательное описание ошибки. |

**Возвращаемое значение:**

Не возвращает значения.

При неравенстве выбрасывает `argument.invalid_value`. Ожидаемое значение безопасно преобразуется в строку и
сохраняется в поле `Ожидание`; непредставимое значение не прерывает формирование исходной ошибки.

## ПроверитьДопустимоеЗначение

```bsl
ПроверкаАргументов.ПроверитьДопустимоеЗначение(
    <ИмяАргумента>, <Значение>, <ДопустимыеЗначения>, <Сообщение> = ""
)
```

Проверяет вхождение аргумента в набор допустимых значений.

**Параметры:**

| Имя | Тип и значение по умолчанию | Описание |
| --- | --- | --- |
| ИмяАргумента | `Строка` | Имя проверяемого аргумента. |
| Значение | `Произвольный` | Проверяемое значение. |
| ДопустимыеЗначения | `Массив`, `ФиксированныйМассив` | Непустой набор допустимых значений. |
| Сообщение | `Строка = ""` | Необязательное описание ошибки. |

**Возвращаемое значение:**

Не возвращает значения.

Если значение отсутствует в наборе, выбрасывает `argument.invalid_value`. Текст поля `Ожидание` формируется из
безопасных представлений элементов набора.

## ПроверитьДиапазон

```bsl
ПроверкаАргументов.ПроверитьДиапазон(
    <ИмяАргумента>,
    <Значение>,
    <МинимальноеЗначение>,
    <МаксимальноеЗначение>,
    <Сообщение> = ""
)
```

Проверяет нахождение аргумента во включительном диапазоне.

**Параметры:**

| Имя | Тип и значение по умолчанию | Описание |
| --- | --- | --- |
| ИмяАргумента | `Строка` | Имя проверяемого аргумента. |
| Значение | `Число`, `Дата` | Проверяемое значение. |
| МинимальноеЗначение | `Число`, `Дата` | Включительная нижняя граница того же типа. |
| МаксимальноеЗначение | `Число`, `Дата` | Включительная верхняя граница того же типа. |
| Сообщение | `Строка = ""` | Необязательное описание ошибки. |

**Возвращаемое значение:**

Не возвращает значения.

Границы включены. Для значения вне диапазона выбрасывается `argument.out_of_range`, а в данных сохраняются
`ИмяАргумента` и строка `ОжидаемыйДиапазон`.

## Ошибки

Собственные параметры процедур также проверяются. Возможны следующие стандартные коды:

| Код | Условие |
| --- | --- |
| `argument.invalid_type` | Параметр имеет недопустимый тип или имя типа не зарегистрировано |
| `argument.required` | Проверяемое значение или обязательный параметр не заполнены |
| `argument.invalid_value` | Условие нарушено либо нижняя граница больше верхней |
| `argument.out_of_range` | Проверяемое число или дата находятся вне включительного диапазона |

Для `ПроверитьДиапазон()` значение и обе границы должны иметь один тип: `Число` или `Дата`.

## Пример

```bsl
ПроверкаАргументов.ПроверитьТип("Порт", Порт, Тип("Число"));
ПроверкаАргументов.ПроверитьЗаполненность("Адрес", Адрес);
ПроверкаАргументов.ПроверитьДопустимость(
    "Порт",
    Порт >= 1 И Порт <= 65535,
    "число от 1 до 65535"
);
ПроверкаАргументов.ПроверитьРавенство("Статус", Статус, ОжидаемыйСтатус);
ПроверкаАргументов.ПроверитьДопустимоеЗначение("Режим", Режим, ДопустимыеРежимы);
ПроверкаАргументов.ПроверитьДиапазон("Порт", Порт, 1, 65535);
```

Фактическое значение в ошибке не сохраняется. Параметры проверок проходят
структурированные проверки собственных контрактов.

Если ошибку нужно сформировать без немедленного исключения, используйте
[`ФабрикаОшибок`](ФабрикаОшибок.md).
