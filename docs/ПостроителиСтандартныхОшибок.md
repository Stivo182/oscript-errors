# ПостроителиСтандартныхОшибок

Публичный модуль создаёт настроенные экземпляры `ПостроительОшибки` для стандартных машинных кодов.

## Оглавление

- [Общий контракт](#общий-контракт)
- [Использование](#использование)
- [Каталог построителей](#каталог-построителей)

- [Связанные сущности](#связанные-сущности)

## Общий контракт

```bsl
Построитель = ПостроителиСтандартныхОшибок.<ИмяФабрики>(
    <ДиагностическиеПараметры>,
    <Сообщение> = ""
);
```

Все функции возвращают `ПостроительОшибки`. Диагностические параметры каталога передаются в указанном порядке.
Все они имеют тип `Строка` и должны быть непустыми, кроме `ФактическоеЗначение`, которое может иметь любой тип.
`Сообщение` имеет тип `Строка`; пустая строка заменяется стандартным локализованным сообщением.

Особые сигнатуры:

```bsl
Построитель = ПостроителиСтандартныхОшибок.НеверныйТипАргумента(
    <ИмяАргумента>,
    <ОжидаемыйТип>,
    <ФактическоеЗначение>,
    <Сообщение> = ""
);
Построитель = ПостроителиСтандартныхОшибок.НедопустимоеЗначениеАргумента(
    <ИмяАргумента>,
    <Ожидание>,
    <Сообщение> = ""
);
Построитель = ПостроителиСтандартныхОшибок.АргументВнеДиапазона(
    <ИмяАргумента>,
    <ОжидаемыйДиапазон>,
    <Сообщение> = ""
);
Построитель = ПостроителиСтандартныхОшибок.ДанныеСлишкомБольшие(
    <ИмяДанных>,
    <Ограничение>,
    <Сообщение> = ""
);
Построитель = ПостроителиСтандартныхОшибок.ДанныеНеСоответствуютКодировке(
    <ИмяДанных>,
    <Кодировка>,
    <Сообщение> = ""
);
```

Остальные функции принимают один диагностический параметр и необязательное `Сообщение`.

## Использование

```bsl
Ошибка = ПостроителиСтандартныхОшибок.РесурсНеНайден("config.json")
    .Данные("Каталог", КаталогНастроек)
    .Подсказка("Проверьте путь к файлу")
    .URL("https://example.org/errors/resource.not_found")
    .Построить();
```

Построитель уже содержит код, сообщение и перечисленные данные. У `НеверныйТипАргумента()` сохраняется строковое
имя `ФактическийТип`, а не `ФактическоеЗначение`. До вызова `Построить()` результат можно дополнить данными,
подсказкой, URL и причиной.

## Ошибки

| Код | Условие |
| --- | --- |
| `argument.invalid_type` | Диагностический параметр или `Сообщение` имеют недопустимый тип |
| `argument.required` | Обязательный диагностический параметр не заполнен |

Создаваемая предметная ошибка при вызове фабрики не выбрасывается.

Диагностические строки должны быть безопасны для журналирования. Фабрики не сохраняют содержимое ресурсов,
исходные исключения, полные URI или реквизиты доступа автоматически.
